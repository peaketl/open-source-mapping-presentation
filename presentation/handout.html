Open-Source Mapping Stack — PostGIS Queries

queries.sql  ·  connect: psql $DATABASE_URL

1 · Row counts

SELECT
  count(*)                            AS total,
  count(*) FILTER (WHERE solved)      AS solved,
  count(*) FILTER (WHERE NOT solved)  AS unsolved
FROM crimes;

2 · ST_AsText — see the geometry

SELECT title, ST_AsText(geom) AS wkt
FROM crimes LIMIT 5;

Converts the binary geom column to human-readable WKT coordinates.

3 · ST_AsGeoJSON — export a row

SELECT title, ST_AsGeoJSON(geom) AS geojson
FROM crimes WHERE id = 1;

Same format MapLibre and most web APIs consume directly.

4 · ST_DWithin — radius search

-- Crimes within 1 mile of downtown Colorado Springs
SELECT title, year, solved
FROM crimes
WHERE ST_DWithin(
  geom::geography,
  ST_MakePoint(-104.8214, 38.8339)::geography,
  1609            -- metres (1 mile)
)
ORDER BY year;

::geography cast → PostGIS works in metres; no projection math needed.

5 · KNN — nearest neighbours

SELECT title,
  round(ST_Distance(
    geom::geography,
    ST_MakePoint(-104.8214, 38.8339)::geography
  )::numeric) AS dist_m
FROM crimes
ORDER BY geom::geography
  <-> ST_MakePoint(-104.8214, 38.8339)::geography
LIMIT 5;

<-> is the KNN distance operator — index-accelerated via GiST.

6 · Aggregate by decade

SELECT (year/10*10)::text||'s' AS decade,
  count(*) AS cases,
  round(100.0
    * count(*) FILTER (WHERE solved)
    / count(*)) AS pct_solved
FROM crimes
GROUP BY decade ORDER BY decade;

7 · ST_Buffer — zone of interest

WITH zone AS (
  SELECT ST_Buffer(
    ST_MakePoint(-104.8214, 38.8339)::geography,
    2000            -- metres (2 km radius)
  )::geometry AS circle
)
SELECT count(*) AS crimes_within_2km
FROM crimes, zone
WHERE ST_Within(geom, zone.circle);

8 · ST_Centroid — geographic center

SELECT ST_AsText(
  ST_Centroid(ST_Collect(geom))
) AS center_of_all_crimes
FROM crimes;

ST_Collect aggregates all points; ST_Centroid finds their geographic center.
