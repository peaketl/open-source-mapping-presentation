Quick Start

cp .env.sample .env
python3 -m pip install -r requirements.txt
./start.sh

start.sh builds and starts all three containers, then runs load_data.py to seed PostGIS.

Environment (.env)

POSTGRES_DB=kenda_cases
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
DATABASE_URL=postgresql://postgres:postgres\
  @localhost:5432/kenda_cases

Useful Commands

# Inspect running containers
podman ps

# Open a psql shell
psql $DATABASE_URL

# Count loaded cases
psql $DATABASE_URL -c "SELECT count(*) FROM crimes;"

# Check spatial index
psql $DATABASE_URL -c "\d crimes"

# Re-run loader after editing crimes.json
python3 load_data.py

PostGIS Schema (key columns)

id
SERIAL PRIMARY KEY
title
TEXT NOT NULL
year
INTEGER
crime_type
TEXT
solved
BOOLEAN
lat / lon
DOUBLE PRECISION
geom
GEOMETRY(Point, 4326) — spatial index via GIST
-- Geometry is computed on insert:
ST_SetSRID(ST_MakePoint(lon, lat), 4326)

Martin Config (martin.yaml)

postgres:
  connection_string: ${DATABASE_URL}
  auto_publish:
    tables: true
    from_schemas: public
listen_addresses: "0.0.0.0:3000"

Martin auto-discovers and publishes every table in the public schema that has a geometry column — no additional config needed when you add a new table.
